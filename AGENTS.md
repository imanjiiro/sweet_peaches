# AGENTS.md

## Что это

Веб-сервис с вычислительным ядром: параметры симуляции → расчёт →
результат.

## Стек (не менять без ADR)

Python 3.12+, Django 5.x, pytest + pytest-django, ruff.

## Архитектурные ограничения — обязательны

1. `core/` не импортирует Django, не ходит в БД и HTTP.
2. Views не содержат логики расчёта — вызывают `core/` и сохраняют
   результат в модели.
3. Секреты — только в `.env`, в коде их нет.

## Как работать

- Малые шаги: одно изменение — один тест — один коммит.
- Не «чини» падающий тест, меняя проверку, — объясни, почему падает.
- Не уверен, что пакет существует, — скажи, не выдумывай.
